# Backlog

This backlog contains only the features currently included in the MVP.

## Frontend

- As a developer, I want a documentation page on the website so that I know how to set up WatchTower in my software and answer any questions I have about how it works.
- As a developer, I want to monitor website uptime and service availability so that I can detect outages or inaccessible services and ensure the application remains operational for users.

## Backend

- As a developer, I want to use a performance metric app that does not slow down my own app, so that the performance errors I see are due to my app and not WatchTower slowing my app down.
- As a developer, I want to receive notifications when the application experiences downtime so that I can quickly respond before they significantly impact users.
- As a user, I want to avoid false alarms from my website going down. I want the application to periodically check for downtime and, if the app is down for more than 3 checks, notify me, in order to minimize being notified when the website is experiencing infrequent downtime that resolves by itself.
