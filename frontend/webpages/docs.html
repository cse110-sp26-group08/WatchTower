Getting started

1. Register your app in WatchTower

Once you have created an account, register the app you want to monitor through the App Selection page. You can optionally add a URL to monitor for uptime. WatchTower automatically polls your app's URL every 5 minutes to check if it is reachable and will alert you by email if it goes down. After the app is created, WatchTower will generate a unique API key for it. Copy this API key because you will need it when adding the collector script to your project.

2. Adding collector.js

The WatchTower collector is a single JavaScript file that you add to your own web app. It tracks JavaScript errors, page performance, and API latency automatically.

Download collector.js

3. Add the collector script to your HTML

Add the following script tag to the <head> or near the end of the <body> in each HTML page you want WatchTower to monitor. Set data-apikey with the unique API key that was generated for your app. Set data-release to a version number or a git commit SHA so performance data is connected to a specific release. 

<script
    id="collector-script"
    src="/scripts/collector.js"
    data-apikey="YOUR_API_KEY"
    data-release="1.0.0">
  </script>

FAQs

What does WatchTower do?

WatchTower helps developers a way to monitor their web apps. It helps teams see whether an app is reachable, review metrics, and get notified when the app is unreacable, allowing developers to respond to crashes quickly.

What data does the collector send to WatchTower?

The collector sends information about unhandled JavaScript exceptions, unhandled promise rejections, page load performance, DOM content loaded time, time to first byte, JavaScript memory usage, and the latency of fetch API requests.

Can I monitor more than one app?

Yes. Each registered app gets its own API key, so you can track multiple projects separately in WatchTower.

Does WatchTower affect my apps performance?

Not significantly. A small browser script reports errors and timing in the background without changing your server or build. Heavy work stays on WatchTower’s side, so normal use should not slow your app down.

Can I use WatchTower during local development?

Yes. WatchTower can be used locally while running the server on http://localhost:3000. If your WatchTower instance is hosted elsewhere, open collector.js and modfify baseUrl 

const baseUrl = "https://your-watchtower-host.com";
